# ATmega2560 Smart Parking

## About the Project
This project is designed to monitor parking slots and assist with parking using the ATmega2560 microcontroller. It focuses on embedded system development for detecting vehicle presence, checking slot availability, and providing status indication through hardware modules.

## Features
- Parking slot monitoring
- Vehicle detection
- Slot availability indication
- LED indication
- Sensor-based detection
- 7-segment display
- Timer-based control

## Hardware
- ATmega2560
- IR Sensor
- Ultrasonic Sensor
- LEDs
- 7-Segment Display
- Push Button/Switch

## Software
- Embedded C
- ATmega2560
- Register-level programming
- Arduino IDE

## Project Structure
The repository contains custom driver modules and related embedded code organized under the `DRIVERS` folder.
